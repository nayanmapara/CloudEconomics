# CloudMart Resource Tagging & Cost Governance Lab

This package contains everything you need to run the Streamlit app and submit the Week 10 Lab.

## Files Included
- app.py — Streamlit dashboard app
- cloudmart_multi_account.csv — dataset
- untagged_resources.csv — automatically generated untagged resources list
- remediated_resources.csv — simulated remediated dataset
- cloudmart_report.md — short summary report
- requirements.txt — dependencies for running the app

## How to Run

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

3. The app will open in your browser at http://localhost:8501
